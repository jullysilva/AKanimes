# AKanimes

[🇧🇷 Português](README.md) | 🇺🇸 English

Anime news website with a featured home page, a news article page and a comment section saved in real time to **Firebase**.

🔗 **Live:** https://jullysilva.github.io/AKanimes/

## Features

- Home page with featured news
- Navigation between home, news, contact and about
- Comment form stored in Firebase Realtime Database

## Stack

- HTML5, CSS3 and JavaScript
- Bootstrap 4.3
- Firebase Realtime Database
- GitHub Pages (hosting)

## Structure

```
index.html     # Main page
css/style.css  # Styles
js/script.js   # Firebase integration and comments
img/           # Images and logo
```

## Getting started

No build step. Open `index.html` in the browser or serve the folder locally:

```bash
npx serve .
```
